常用设置
站点页自动刷新频率，默认 60 秒
PT 站数据不频繁变化，缓存期内刷新页面/切换/保存都不会真实访问站点，默认 300 秒
下载器默认 15 秒、站点默认 60 秒。改小刷新更快，但会增加下载器 API 请求频率，建议下载器不小于 5 秒。站点与下载器的添加 / 编辑 / 删除已移至各自页面。
飞牛影视（首页影视墙）
填写飞牛影视（fnOS 影视）Web 地址与账号。首页影视墙将显示媒体库统计、继续观看与海报墙。凭证仅保存在 NAS 本地配置文件。修改后自动保存生效。
Docker 容器监控
「允许容器启停」默认关闭。开启后首页容器卡片会出现 启动 / 停止 / 重启 / 暂停 按钮——停止容器会中断该容器提供的服务，请确认后果后再开启。
启用 Docker 容器监控后，这里可配置首页显示哪些 Docker 组件及其顺序。
首页「系统监控」下方按此处顺序显示所选组件：健康总览（运行 / 停止 / 异常）、资源占用 Top、网络流量 Top（实时收发速率）、容器列表（全部容器状态）。打开「编辑」可重新勾选与排序；组件数据来自 Docker Engine API，需挂载 docker.sock 或提供可访问的 Docker API 地址。
MoviePilot（首页深度看板）
MoviePilot 的 Web 访问地址
「MoviePilot」独立页展示媒体库统计、下载器汇总、系统资源、存储与订阅概况，支持搜索影视资源一键订阅、查看已安装插件。API Token 在 MoviePilot 的「设置 - 服务」中获取；填写后点保存即可生效。插件列表缓存 10 分钟，可手动刷新。所有凭证仅保存在 NAS 本地配置文件。
历史趋势
后台按间隔自动采样（默认 60 分钟），记录 CPU / 内存 / 磁盘、上传下载速率、站点在线数与分享率。数据按天存为 JSONL，超过保留天数自动清理。首页「系统监控」下方显示趋势曲线。
告警通知
站点连续离线达到设定次数、分享率低于下限（0 = 不检查）、磁盘使用率超过水位（0 = 不检查）、容器异常时推送。同一问题在重复间隔内不重复推送，恢复后推一条「已恢复」。
通知渠道
「测试通知」向所有已勾选渠道发一条测试消息；「立即检查」按当前规则跑一次判定（告警未启用时只列出命中项、不推送）；「清空告警状态」清除去重记录与事件列表。凭证仅保存在 NAS 本地配置文件。
主题外观
点击预设或直接用取色器选自定义颜色
界面布局
主题所有设置立即生效并自动保存；只影响本面板界面，不影响数据。
背景图片
当前使用的是本地上传的背景图（存放在 NAS 的 config 目录，不占配置文件体积） 上传的图片会自动压缩后单独保存在 NAS 上（不再塞进 config.json）；设了背景图片后自动叠加半透明遮罩保证文字可读。清除后恢复默认渐变。
数据备份与恢复
下载完整配置（含全部站点 / 下载器 / 飞牛凭证）到本地保存
选择之前导出的 .json 备份文件恢复；恢复前自动备份当前配置
备份文件只应保存在你自己的设备 / NAS 上，不要上传到任何公开位置。
